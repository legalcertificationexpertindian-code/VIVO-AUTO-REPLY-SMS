# AUTO SMS — Vivo T4 Pro

Branding: AUTO SMS, user-supplied blue/teal logo. Dashboard UI with compact weekly schedules, master switch, Friday lunch, holiday overrides, SIM selection and last attempt.

## GitHub upload
Replace the contents of your existing `VivoAutoReply-Final-Source` folder with this folder's contents. Keep your `.github/workflows/build.yml` at repository root. Run the workflow and download the debug APK artifact.

## Important
This source is not yet device-verified. The receiver uses call-log checks and may be limited by Android 16/OriginOS battery restrictions and permissions. Test on your Vivo with a second phone and confirm actual SMS delivery. Carrier charges may apply. Only unanswered missed calls should trigger messages.
